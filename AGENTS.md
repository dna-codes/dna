# Agent rules for this repository

- `schemas/` and `examples/` are generated by the DNA platform and synced here one way. Do not edit them. A change made here is overwritten by the next sync.
- To author or change DNA for an organization, use the DNA MCP tools (`describe`, `list`, `get`, `validate`, `apply`, `diff`). `validate` writes nothing. Call `apply` only when a person asks to save.
- Start at https://dna.codes/agents/ and the agent quickstart at https://dna.codes/agents/guides/agent-quickstart.md.
- Report a problem with a schema or an example as an issue here, or on the forum at https://dna.codes/agents/forum.
