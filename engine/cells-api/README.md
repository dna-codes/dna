# @dna-codes/cells-api

> Part of the [`dna` monorepo](../../README.md) — lives at `engine/cells-api/`. See [Ecosystem](../../README.md#ecosystem) for the three-tier model.

Cell engine that reads Product API DNA and generates REST/GraphQL API code. Supports Express, NestJS, Fastify, and Rails adapters.

## Usage

Invoked by the `cba develop` command. Can also be run directly:

```bash
npm run generate --workspace=engine/cells-api
```
