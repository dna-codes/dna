# @dna-codes/cells-ui

> Part of the [`dna` monorepo](../../README.md) — lives at `engine/cells-ui/`. See [Ecosystem](../../README.md#ecosystem) for the three-tier model.

Cell engine that reads Product UI DNA and generates React UI components, Astro pages, and Next.js routes.

## Usage

Invoked by the `cba develop` command. Can also be run directly:

```bash
npm run generate --workspace=engine/cells-ui
```
