# @dna-codes/cells-db

> Part of the [`dna` monorepo](../../README.md) — lives at `engine/cells-db/`. See [Ecosystem](../../README.md#ecosystem) for the three-tier model.

Cell engine that reads Operational DNA and generates database schemas and migration files.

## Usage

Invoked by the `cba develop` command. Can also be run directly:

```bash
npm run generate --workspace=engine/cells-db
```
