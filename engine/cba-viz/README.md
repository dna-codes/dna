# @dna-codes/cells-viz

> Part of the [`dna` monorepo](../../README.md) — lives at `engine/cba-viz/`. See [Ecosystem](../../README.md#ecosystem) for the three-tier model.

Interactive architecture viewer for cell-based DNA deployments. Vite + React + JointJS.

## Usage

```bash
npm run dev --workspace=engine/cba-viz
```

Opens a browser-based visualization of a DNA graph.
